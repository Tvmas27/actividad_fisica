# Dashboard de Actividad Física

Proyecto para visualizar KPIs de actividad física y sedentarismo con frontend estático y backend Flask.

## Ejecución

```bash
pip install -r requirements.txt
python app.py
```

El dashboard queda disponible en `http://localhost:5000`.

## API disponible

- `/api/kpi/nivel_oms`
- `/api/kpi/rango_etario`
- `/api/kpi/sedentarismo`
- `/api/kpi/tipo_actividad`
- `/api/kpi/correlacion`
- `/api/kpi/usa_app`
- `/api/sla`
- `/api/quality`
